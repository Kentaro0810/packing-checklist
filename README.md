# 持ち物チェックリスト

旅行、学校、部活動などの持ち物を用途別リストで管理する静的Webアプリです。

## 主な機能
- 複数リストの作成・編集・削除
- 持ち物名・カテゴリー・数量の登録
- 準備済みチェックと進捗率
- 持ち物検索とカテゴリー絞り込み
- 学校・サッカー・旅行テンプレート
- 準備済み項目の一括削除
- チェックの一括解除
- JSONバックアップ
- PC、タブレット、スマートフォン対応

## 公開方法
1. GitHubで `packing-checklist` というPublicリポジトリを作成します。
2. 4ファイルをアップロードします。
3. Settings → Pagesでmainブランチのrootを公開します。
